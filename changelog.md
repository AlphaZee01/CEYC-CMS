# Changelog

## [2025-05-22] — Christ Embassy Local Church Management System

### Added
- Single-file React application (`src/App.tsx`) for Christ Embassy Local Church Management System
- 16 feature pages: Dashboard, Members, Cells & Fellowships, Ministry Departments, Attendance, Events, Reports, Settings, Communications, Finances, Prayer Requests, Discipleship, Announcements, Tasks, Media Library, Report Submissions
- Role-based access control for all church hierarchy roles (Senior Pastor through Church Member)
- Pre-loaded mock data for demonstrations across all modules
- Recharts analytics (member growth, attendance trends, department participation)
- Lucide React icons throughout sidebar and UI
- Demo role switcher in Settings to simulate different user perspectives
- Deep purple / teal / coral color theme in `src/index.css`
- CSV export for reports and financial data
- Mobile-responsive sidebar with collapsible navigation

### Changed
- Replaced e-commerce storefront with church management system as primary `App.tsx`
- Updated `index.html` title and meta description for Christ Embassy LCM
